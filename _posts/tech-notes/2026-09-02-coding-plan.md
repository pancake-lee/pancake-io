## 背景与使用模式

先交代使用模式，它决定了后面的所有结论：我目前处于职业 Gap 期，写代码的频率不算高，也算不上重度用户。

长期以来我的组合是 DeepSeek API + Claude Code，按量付费，用多少付多少。质量稳定，成本可控，我对这个组合一直比较满意。

变化来自 DeepSeek 升价。升价后实际使用了两天，一天的成本大约变成以前的 3～4 倍，一周累计消耗 100 元以上，并且计费区分高峰/空闲时段。成本结构和使用的确定性都变差了，于是决定系统性地看一圈市面上的 Coding Plan。

## 评估维度

横向对比时我关注这几个维度：

| 维度 | 说明 |
| --- | --- |
| 代码能力 | 理解需求、写对代码、改 bug 的能力 |
| 上下文管理 | 长会话、大仓库下的记忆与注意力 |
| 工具调用可靠性 | 执行命令/读写文件/搜索时的出错率 |
| 价格 | 实际花费感知，包括 cache、思考 token 的计费细节 |
| 速度 | 响应延迟、思考时间占比 |
| 配置成本 | 接入、权限、环境折腾程度 |

对套餐制的 Coding Plan 来说，还多一个硬约束：额度。5 小时限制、周限制、月额度分别是多少，按我的使用强度能撑多久，这往往比单价更早决定去留。下面的实测里，额度基本是主要矛盾。

## 国内各家低档套餐实测

### Kimi（月之暗面）

之前订阅过一个月 199 元档套餐。当时的结论是价格、额度、输出质量三项都差一点意思，没有一项突出到值得留下，所以这次没有再重点测试。

### 千问（阿里）

最低档 39 元。周额度按我的使用强度只够一小时左右，连感受输出质量的时间都不够，无法形成有效评价。价格门槛低，但额度门槛先卡住了。

### 智谱 GLM

最低档 118 元，此前长期是抢购状态，这次发现可以直接购买。两个方面的记录：

- **质量**：与 DeepSeek 相当，个别场景甚至略好，不明显。
- **速度与额度**：输出速度明显更慢，直觉上慢了一倍以上；5 小时限制按我的使用强度一两个开发任务就会打满，周额度大约够用两天。额度耗尽后我只能切回 DeepSeek 兜底。

综合看质量可以接受，速度和额度是硬伤，118 元档对我的强度完全不够用。

### Qoder

注册赠送 300 积分。三点记录：

1. 产品分国内国外版本，国内版命令行叫 qoderclicn，命名不太讲究。
2. 输出质量明显低于 DS + Claude Code。我用一个真实的前端布局问题做对比测试：第一版效果差，反馈 3～4 轮后仍达不到我认为「基本合格」的程度；同一问题切回 DS + Claude Code，一轮就修到了基本满意的布局。
3. 测试时 Qoder 用的是 Auto 模式，无法确认是否调用到了最高档模型，所以这个结论只对「默认体验」成立。但既然默认路径拿到的就是这个质量，对新用户的参考价值是足够的。赠送额度用完后我没有再付费对比。

### 阶段结论

国内低档套餐（40～200 元档）对我的使用强度都不够用：要么额度撑不住，要么质量差一口气。套餐耗尽后只能 DeepSeek 兜底，并没有真正缓解账单压力。

## 转向 Codex

之前一直没订 ChatGPT 套餐，卡在两件事上：网络和支付。

「环境」一直有，但偶尔会抖；支付则试过手机验证码和国内 Mastercard，都失败了。网上有各种代充、接码、中转方案，我不想为了订一个工具引入额外的风险和时间成本，一直没有走这些路。

转机是发现可以走 Google Play 订阅，而且从华为换成 Vivo 之后，这条路顺手了很多。具体做法：家里留一个走代理的 Wi-Fi（设置为永不自动连接 + 手动代理，代理来自电脑端的客户端），手机只在这个 Wi-Fi 下操作 Google 相关服务；在 Google Play 里新建账号、下载 ChatGPT 应用、登录并购买。

先买的是 8 美元的 Go 套餐，目的只有一个：验证 Codex 值不值得继续投入。结论是肯定的，GPT-5.6 的编码体验比我之前的 DS + Claude Code 明显好一个小等级。问题在于额度：Go 给的是整月总额度，没有 5 小时和周限制，但按我的强度不到一天就用完了。

## 账号被封与解封

Go 额度见底之前准备升级 Plus，发现 Google 账号被封，理由是「此账号似乎是与多个其他账号一起创建或使用的」。

复盘下来，问题大概率出在「环境」的稳定性上：

- 中途有几次没注意 Wi-Fi，在没有代理的国内网络下访问了 Google Play；
- 甚至还用国内手机号完成了一次安全验证;
- 短时间内跨地区 IP 来回切换，对风控系统来说确实很像异常账号。

处理过程不复杂：参考网友的申诉经验写了一段英文申诉，第二天解封。但停摆一天的心情成本不低。

经验就一句话：跨区使用，稳定比技巧重要。固定设备、固定出口、少切换，比任何「姿势」都有效。

## 升级 Plus 与计费观察

解封后直接升级 Plus。实际账单：

| 时间 | 操作 | 金额 |
| --- | --- | --- |
| 24 号 | 购买 Go（月度） | $8 |
| 26 号 | 升级 Plus | 补差价 $11.37 |
| 下月 24 号 | Plus 续费 | $20 |

两个观察：

1. 升级是按当前计费周期折算差价的，不是简单补一个月的差价。为什么是 11.37 而不是 12，我没有深究，推测与按天折算有关。
2. 这个机制意味着「先低档验证、确认值得再升级」的策略几乎没有成本浪费，验证期花的钱会被折算进去。对我这种不想一步到位订阅的人来说，是个友好的设计。

## 结论与现状

把整个过程的结论收拢一下：

1. 对我的使用强度，国内 40～200 元档套餐的额度都撑不起主力使用，只适合作为补充或尝鲜。
2. 实际用下来，ChatGPT Plus 比我开过的国内同价位套餐更耐用。可能的原因之一是国产模型接入 Claude Code 这类第三方 CLI 时消耗更高（这一点没有严格验证，是使用感知）；另一面也说明国产的 Code Agent 产品本身还有差距，得加油追赶。
3. 单价不是唯一的成本变量。一个质量更好的模型能减少返工和纠正的轮次，少反馈三轮省下的时间和 token，可能足以覆盖差价。对重度 Coding 用户来说，最便宜的不一定最省钱。
4. 现状：以 ChatGPT Plus 为主，DS + Claude Code 按量付费兜底。后面观察 Plus 的额度到底能撑多久，有新数据再来更新。
